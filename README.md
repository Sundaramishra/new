# Cliniva CRM - Hospital & Clinic Management System

## Tech Stack
- HTML, CSS, JS (Frontend)
- PHP (Backend)
- MySQL (Database)

## Features
- Multi-role login (Admin, Doctor, Patient, Nurse, Staff, Pharmacy, Lab Tech, Receptionist, Intern)
- Responsive, customizable UI (Cliniva Angular theme inspired)
- Modular structure (easy to add new modules)
- Secure authentication (encrypted passwords)
- All major hospital/clinic management modules (appointments, billing, pharmacy, lab, etc.)

## Structure
- `index.html` - Homepage
- `style.css` - Main stylesheet
- `main.js` - JS for UI interactions (e.g., dark mode)
- `assets/` - Images, logo, favicon, etc.
- `php/` - All PHP backend files (to be added)
- `sql/` - Database schema (to be added)
- `modules/` - All role/module specific pages (to be added)

## Customization
- Change logo, favicon, title, color, and enable day/night mode from settings (UI coming soon)
